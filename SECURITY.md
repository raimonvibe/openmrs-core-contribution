# Security Policy

## Supported versions

This repository is a personal contribution fork of OpenMRS Core.
Security fixes are applied on the default branch (`feature/windows-setup-guide`).

## What is a vulnerability

A vulnerability is any issue that can lead to unauthorized access, data
disclosure, remote code execution, privilege escalation, or integrity
loss in OpenMRS Core or this fork.

## Reporting a vulnerability

Please report security issues privately to <security@openmrs.org>
(upstream OpenMRS) and, for this fork, open a private GitHub security
advisory at https://github.com/raimonvibe/openmrs-core-contribution/security/advisories/new

Do **not** file a public issue for unfixed security problems.

## Response timeline

- We acknowledge private reports within 7 days.
- We aim to publish a fix or mitigation within 30 days when a patch is practical on this fork.
- If a report is declined, we will say why (for example: already fixed upstream, or not exploitable here).
